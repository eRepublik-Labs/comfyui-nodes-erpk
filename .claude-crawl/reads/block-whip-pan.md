# [​](https://hyperframes.heygen.com/catalog/blocks/whip-pan\#whip-pan)  Whip Pan

Shader transition simulating a fast camera whip pan`transition``shader`

## [​](https://hyperframes.heygen.com/catalog/blocks/whip-pan\#install)  Install

Terminal

```
npx hyperframes add whip-pan
```

## [​](https://hyperframes.heygen.com/catalog/blocks/whip-pan\#usage)  Usage

After installing, add the block to your host composition:

```
<div data-composition-id="whip-pan" data-composition-src="compositions/whip-pan.html" data-start="0" data-duration="4" data-track-index="1" data-width="1920" data-height="1080"></div>
```
