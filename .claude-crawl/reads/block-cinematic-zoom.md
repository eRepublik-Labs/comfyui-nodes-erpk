# [​](https://hyperframes.heygen.com/catalog/blocks/cinematic-zoom\#cinematic-zoom)  Cinematic Zoom

Shader transition with dramatic zoom blur`transition``shader`

## [​](https://hyperframes.heygen.com/catalog/blocks/cinematic-zoom\#install)  Install

Terminal

```
npx hyperframes add cinematic-zoom
```

## [​](https://hyperframes.heygen.com/catalog/blocks/cinematic-zoom\#details)  Details

## [​](https://hyperframes.heygen.com/catalog/blocks/cinematic-zoom\#usage)  Usage

After installing, add the block to your host composition:

```
<div data-composition-id="cinematic-zoom" data-composition-src="compositions/cinematic-zoom.html" data-start="0" data-duration="4" data-track-index="1" data-width="1920" data-height="1080"></div>
```
