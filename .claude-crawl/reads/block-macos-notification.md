# [​](https://hyperframes.heygen.com/catalog/blocks/macos-notification\#macos-notification)  macOS Notification

## [​](https://hyperframes.heygen.com/catalog/blocks/macos-notification\#install)  Install

Terminal

```
npx hyperframes add macos-notification
```

```

```
