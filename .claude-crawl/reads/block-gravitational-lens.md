# [​](https://hyperframes.heygen.com/catalog/blocks/gravitational-lens\#gravitational-lens)  Gravitational Lens

Shader transition with gravitational lensing distortion`transition``shader`

## [​](https://hyperframes.heygen.com/catalog/blocks/gravitational-lens\#install)  Install

Terminal

```

```
