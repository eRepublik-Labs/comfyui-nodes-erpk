# [​](https://hyperframes.heygen.com/catalog/blocks/ui-3d-reveal\#3d-ui-reveal)  3D UI Reveal

## [​](https://hyperframes.heygen.com/catalog/blocks/ui-3d-reveal\#install)  Install

Terminal

```
npx hyperframes add ui-3d-reveal
```

## [​](https://hyperframes.heygen.com/catalog/blocks/ui-3d-reveal\#usage)  Usage

After installing, add the block to your host composition:

```
<div data-composition-id="ui-3d-reveal" data-composition-src="compositions/ui-3d-reveal.html" data-start="0" data-duration="13" data-track-index="1" data-width="1920" data-height="1080"></div>
```
