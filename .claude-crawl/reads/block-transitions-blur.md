# [​](https://hyperframes.heygen.com/catalog/blocks/transitions-blur\#blur-transitions)  Blur Transitions

Showcase of blur-based transitions between scenes`transition``showcase`

## [​](https://hyperframes.heygen.com/catalog/blocks/transitions-blur\#install)  Install

Terminal

```
npx hyperframes add transitions-blur
```

## [​](https://hyperframes.heygen.com/catalog/blocks/transitions-blur\#usage)  Usage

After installing, add the block to your host composition:

```
<div data-composition-id="transitions-blur" data-composition-src="compositions/transitions-blur.html" data-start="0" data-duration="20" data-track-index="1" data-width="1920" data-height="1080"></div>
```
