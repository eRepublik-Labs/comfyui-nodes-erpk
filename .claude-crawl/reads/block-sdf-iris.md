# [​](https://hyperframes.heygen.com/catalog/blocks/sdf-iris\#sdf-iris)  SDF Iris

Shader transition with signed distance field iris reveal`transition``shader`

## [​](https://hyperframes.heygen.com/catalog/blocks/sdf-iris\#install)  Install

Terminal

```
npx hyperframes add sdf-iris
```

