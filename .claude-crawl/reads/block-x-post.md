# [​](https://hyperframes.heygen.com/catalog/blocks/x-post\#x-post-card)  X Post Card

Animated X/Twitter post card overlay with engagement metrics`social``overlay``twitter`

## [​](https://hyperframes.heygen.com/catalog/blocks/x-post\#install)  Install

Terminal

```
npx hyperframes add x-post
```

## [​](https://hyperframes.heygen.com/catalog/blocks/x-post\#details)  Details

## [​](https://hyperframes.heygen.com/catalog/blocks/x-post\#usage)  Usage

After installing, add the block to your host composition:

```
<div data-composition-id="x-post" data-composition-src="compositions/x-post.html" data-start="0" data-duration="5" data-track-index="1" data-width="1920" data-height="1080"></div>
```
