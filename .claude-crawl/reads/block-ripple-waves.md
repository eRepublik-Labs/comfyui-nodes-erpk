# [​](https://hyperframes.heygen.com/catalog/blocks/ripple-waves\#ripple-waves)  Ripple Waves

Shader transition with concentric ripple wave distortion`transition``shader`

## [​](https://hyperframes.heygen.com/catalog/blocks/ripple-waves\#install)  Install

Terminal

```
npx hyperframes add ripple-waves
```

## [​](https://hyperframes.heygen.com/catalog/blocks/ripple-waves\#usage)  Usage

After installing, add the block to your host composition:

```
<div data-composition-id="ripple-waves" data-composition-src="compositions/ripple-waves.html" data-start="0" data-duration="4" data-track-index="1" data-width="1920" data-height="1080"></div>
```
